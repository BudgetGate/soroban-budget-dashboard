# BudgetGate Dashboard

BudgetGate Dashboard is a comprehensive data visualization frontend for the BudgetGate Soroban Resource toolkit. It fetches, stores, and graphs the historical resource consumption (CPU Instructions, Memory, Read Bytes, and Write Bytes) for your Soroban smart contracts, helping you visually pinpoint when a regression was introduced.

## Features
- **Historical Analysis:** Track the trajectory of your smart contract resource costs over time.
- **Drill-down:** Inspect specific functions and their individual resource trends.
- **Cyberpunk UI:** An intense, data-first cyberpunk aesthetic for heavy engineering monitoring.

## Architecture

This frontend is a React application built with Vite and TailwindCSS. It fetches JSON outputs generated by `soroban-budget-core` that have been committed and cached by `soroban-budget-action`, generating continuous Recharts graphs.

## Quick Start

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/BudgetGate/soroban-budget-dashboard.git
   cd soroban-budget-dashboard
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173`.

## Deployment

To build for production, run:
```bash
npm run build
```
This generates static files in the `dist/` directory which can be hosted on Vercel, Netlify, or GitHub Pages.
